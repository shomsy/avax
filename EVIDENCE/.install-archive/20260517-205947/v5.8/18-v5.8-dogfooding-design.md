# V5.8-18: V5.8 Dogfooding Design

**Date:** 2026-05-13
**Stage:** V5.8 Design Lock — Dogfooding Design

## Primary Dogfooding Target

**SecureRegistrationApi** — canonical reference flow.

### Entity Lifecycle Dogfooding

```php
// Register entity lifecycle listener
onEntity(User::class)
    ->created(EmitUserRegistered::class);

// Listener bridges DB lifecycle → canonical Events
final readonly class EmitUserRegistered
{
    public function __invoke(EntityCreated $event): void
    {
        emit(new UserRegistered(
            userId: $event->entity->id,
            email: $event->entity->email,
        ));
    }
}
```

**Proof:** Registration flow persists User → fires `EntityCreated` → `EmitUserRegistered` emits `UserRegistered` → V5.7
listeners handle it.

### Transaction Lifecycle Dogfooding

```php
// Register transaction lifecycle listener
onTransaction()
    ->afterCommit(PublishOutboxMessages::class);

// Listener records safe side effect after commit
final readonly class PublishOutboxMessages
{
    public function __invoke(AfterCommit $event): void
    {
        // Publish outbox messages stored during transaction
        // This proves afterCommit runs only after successful commit
    }
}
```

**Proof:** Registration runs inside transaction → `afterCommit` callback buffers → on commit, callback runs → on
rollback, callback is discarded.

### Projection Dogfooding

```php
// V5.7 listener already does this
onEvent(UserRegistered::class)
```

## Required Test Proofs

### Test 1: Entity Lifecycle Hook Invoked

```php
public function test_entity_created_listener_is_invoked(): void
{
    $invoked = false;
    onEntity(TestUser::class)
        ->created(static function () use (&$invoked): void {
            $invoked = true;
        });

    $this->persistUser(new TestUser('test@example.com'));

    self::assertTrue($invoked);
}
```

### Test 2: afterCommit Does NOT Run on Rollback

```php
public function test_after_commit_does_not_run_on_rollback(): void
{
    $committed = false;
    $rolledBack = false;

    onTransaction()
        ->afterCommit(static function () use (&$committed): void {
            $committed = true;
        })
        ->rolledBack(static function () use (&$rolledBack): void {
            $rolledBack = true;
        });

    $this->runInTransaction(function (): void {
        $this->persistUser(new TestUser('test@example.com'));
        throw new RuntimeException('Force rollback');
    });

    self::assertFalse($committed);
    self::assertTrue($rolledBack);
}
```

### Test 3: External Side Effect is After Commit

```php
public function test_side_effect_happens_after_commit(): void
{
    $sideEffectOrder = [];

    onTransaction()
        ->committed(static function () use (&$sideEffectOrder): void {
            $sideEffectOrder[] = 'committed';
        })
        ->afterCommit(static function () use (&$sideEffectOrder): void {
            $sideEffectOrder[] = 'after_commit';
        });

    $this->runInTransaction(function () use (&$sideEffectOrder): void {
        $sideEffectOrder[] = 'inside_transaction';
    });

    self::assertSame(['inside_transaction', 'committed', 'after_commit'], $sideEffectOrder);
}
```

## Rules

1. **Dogfooding must prove lifecycle hooks are not decorative.**
2. **Tests must prove listener is invoked through DB lifecycle.**
3. **Tests must prove afterCommit does not run on rollback.**
4. **Tests must prove external side effect is after commit, not before.**
5. **Do not make production event sourcing claim.**
