# Convert

Convert operations transform collections to different formats.

## Purpose

This folder contains conversion operations.

## Classes

| Class                          | Responsibility           |
|--------------------------------|--------------------------|
| `ConvertCollectionToArray.php` | Convert to array         |
| `ConvertCollectionToJson.php`  | Convert to JSON          |
| `ConvertCollectionToXml.php`   | Convert to XML           |
| `ExpandDotKeys.php`            | Expand dot notation keys |
| `FlattenIntoDotKeys.php`       | Flatten into dot keys    |
