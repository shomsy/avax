## Decorative Phases Reviewed

| Phase          | Status  | Verdict                                                                                                                                             |
|----------------|---------|-----------------------------------------------------------------------------------------------------------------------------------------------------|

| Created        | ACTIVE  | Dispatched by EntityPersister::insert()                                                                                                             |

| Updated        | ACTIVE  | Dispatched by EntityPersister::update()                                                                                                             |

### TransactionLifecyclePhase

| Phase         | Status  | Verdict                                                                                                                                                                                 |
|---------------|---------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Beginning     | ACTIVE  | Dispatched by Transaction::begin()                                                                                                                                                      |
| Committed     | ACTIVE  | Dispatched by Transaction::commit() (outermost)                                                                                                                                         |
| AfterCommit   | ACTIVE  | Dispatched by Transaction::commit() after callbacks                                                                                                                                     |
| RolledBack    | ACTIVE  | Dispatched by Transaction::rollback()                                                                                                                                                   |

| Failed        | ROADMAP | Event class does NOT exist for transaction failed. DSL has failed() method but no runtime dispatches it. Valid for future transaction failure tracking.                                 |

### QueryLifecyclePhase

|-----------|--------|---------------------------------------------------------|
| Executing | ACTIVE | Dispatched by QueryOrchestrator::query()/execute()      |
| Executed  | ACTIVE | Dispatched by QueryOrchestrator::query()/execute()      |

## Summary

- **ACTIVE phases (dispatched by runtime):** 15 of 21 total
- **ROADMAP phases (DSL accepts, no runtime dispatch):** 3 of 21 (EntityRestored, Transaction AfterRollback event
  dispatch, Transaction Failed)
- **Missing event class:** TransactionFailed (TransactionLifecyclePhase::Failed exists but no corresponding event
  object)

## Risk Assessment

ROADMAP phases are not bugs. They are intentional extension points:

- EntityRestored: for future soft-delete restore feature
- Transaction AfterRollback event: afterRollback callbacks exist, lifecycle event dispatch is a future enhancement
- Transaction Failed: reserved for future transaction failure tracking

No immediate action required. These are design-ahead phases, not deceptive ones.
