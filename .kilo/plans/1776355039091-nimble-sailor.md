## ToDo plan za izradu strukture

### Faza 0. Zakljucavanje jezika sistema

Cilj je da pre koda zakljucas recnik i ownership granice.

ToDo:

* potvrditi da su root zone finalne:

  * `Flows`
  * `Access`
  * `Identity`
  * `ExternalIdentity`
  * `IdentitySync`
  * `Tenancy`
  * `Diagnostics`
  * `Configuration`
  * `Foundation`
* potvrditi da je `System/` canonical production root
* zakljucati znacenje svake root zone u jednoj recenici
* zakljucati da `Flows` sadrzi use-case price, a capability zone shared ownership areas
* zakljucati naming pravilo:

  * folder = flow ili capability
  * file = owner
  * function = exact action

Deliverables:

* `docs/architecture/system-shape.md`
* `docs/architecture/flow-boundaries.md`
* `docs/architecture/capability-boundaries.md`

Done kada:

* vise nema otvorene rasprave sta pripada kom root folderu
* isti pojam nema 2 razlicita naziva u sistemu

---

### Faza 1. Tree freeze i ownership mapa

Cilj je da imas stabilan target pre bilo kakvog prebacivanja.

ToDo:

* mapirati svaki postojeci file iz starog sistema na novu lokaciju
* za svaki file zapisati:

  * stara lokacija
  * nova lokacija
  * owner tip: flow / action / state / capability / configuration / foundation
* oznaciti sve fajlove koji vise ne pripadaju novom modelu
* oznaciti sve synonym sudare i duplicate ownere

Deliverables:

* `docs/decisions/ADR-001-system-root.md`
* interni migration map dokument, npr. `docs/architecture/migration-map.md`

Done kada:

* svaki stari owner ima ili novu lokaciju ili oznaku za brisanje
* nema “videcemo kasnije” foldera

### Faza 2. Dokumentovati root ownership pravila

Cilj je da se struktura ne raspadne cim krene implementacija.

ToDo:

* za svaki root folder napisati:

  * sta ne poseduje
  * kada nesto sme da se spusti tu
  * kada nesto mora da ostane lokalno u flow-u
* posebno dokumentovati granice:

  * `Access` vs `Identity`
  * `Identity` vs `ExternalIdentity`
  * `ExternalIdentity` vs `IdentitySync`
  * `Tenancy` vs `Access`
* zapisati zasto je `SCIM` pod `IdentitySync`, a ne pod `ExternalIdentity`

Deliverables:
