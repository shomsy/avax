# V5.8.1 Implementation Audit

Date: 2026-05-13
Stage: V5.8.1 Review Remediation

## Files Modified

### P0 Fixes (4)

1. **CompiledDatabaseLifecycleRegistry.php** — Removed superset expansion from `entityListenersFor()`. Now returns exact
   match only: `return $this->entityListeners[$entityClass][$phase->value] ?? [];`. Superset dispatch is handled
   explicitly by EntityPersister.

2. **GlobalDatabaseLifecycleState.php** (NEW) — Singleton providing shared registry for DSL + runtime. Methods:
   `registry()`, `setRegistry()`, `freeze()`, `isFrozen()`, `reset()`. Solves the DSL/runtime registry split bug.

3. **RedactBindings.php** (NEW) — Static utility for redacting sensitive query bindings. Detects named vs positional
   bindings. Sensitive keys: password, passwd, pass, token, secret, api_key, authorization, etc. Value detection: Bearer
   tokens, JWT patterns, 32+ hex strings.

4. **Transaction.php** — Rewrote `commit()` to separate DB commit success from afterCommit callback failure. Decrements
   nesting before callbacks, fires Committed event, runs callbacks with try/catch. If callback fails: fires AfterCommit
   event with error, throws "AfterCommit callback failed:" exception.

### DSL Registry Wiring (3)

5. **EntityLifecycleDsl.php** — Removed private static `$registry`, now uses `GlobalDatabaseLifecycleState::registry()`.

6. **QueryLifecycleDsl.php** — Same pattern.

7. **TransactionLifecycleDsl.php** — Same pattern.

### Runtime Registry Wiring (2)

8. **EntityPersister.php** — Changed `$registry` param to nullable. Added `getRegistry()` fallback to
   `GlobalDatabaseLifecycleState::registry()`.

9. **QueryOrchestrator.php** — Same nullable registry pattern. Added `RedactBindings::redact()` call in
   `buildQueryEvent()`.
