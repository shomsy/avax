# Compiled Cache Security Model

## No Path Traversal

Artifact names CANNOT contain:

- `..` (parent directory)
- `/` (forward slash)
- `\\` (back slash)

Attempt causes `InvalidArgumentException`.

## No Unsafe Artifact Names

Names must match: `/^[a-zA-Z0-9][a-zA-Z0-9._-]*$/`

Max length: 128 characters.

## No User Input in Executable PHP

Generated PHP files contain ONLY:

- `declare(strict_types=1)`
- Framework-generated `return` arrays
- No user input
- No `$_GET`, `$_POST`, etc.

## Safe PHP File Format

```php
<?php

declare(strict_types=1);

/**
 * This file is generated by Avax Compiled Cache.
 * Do not edit manually.
 */

return [
    'key' => 'value',
];
```

## Permission Expectations

- Directory: `0755` or `0750`
- Files: `0644` or `0640`
- Never execute: no `0755` on PHP files

## Clear Operation Boundaries

- Cannot delete files outside compiled cache directory
- Cannot delete parent directories
- Preserves unrelated files

## Payload Validation

Builders CANNOT return:

- Closures
- Resources
- Objects (unless array-exportable)
- Empty array keys

## Logging

Never log:

- Compiled payload contents
- Source file contents
- User data

## Freshness Checks

Only checks file metadata:

- Mod time
- Checksum (optional)
- No content inspection
