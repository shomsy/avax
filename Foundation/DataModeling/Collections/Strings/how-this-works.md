# Strings

String operations on collection values.

## Purpose

This folder contains string manipulation operations applied to collection items.

## Classes

| Class                 | Responsibility          |
|-----------------------|-------------------------|
| `JoinValues.php`      | Join values into string |
| `UppercaseValues.php` | Convert to uppercase    |
| `LowercaseValues.php` | Convert to lowercase    |
| `TrimValues.php`      | Trim whitespace         |
| `TitleCaseValues.php` | Convert to title case   |
