# Aggregate

Aggregate operations compute single values from collections.

## Purpose

This folder contains aggregation operations that reduce collections to single values.

## Classes

| Class               | Responsibility         |
|---------------------|------------------------|
| `CountValues.php`   | Count items            |
| `SumValues.php`     | Sum numeric values     |
| `AverageValues.php` | Average numeric values |
| `FindMinValue.php`  | Find minimum value     |
| `FindMaxValue.php`  | Find maximum value     |
