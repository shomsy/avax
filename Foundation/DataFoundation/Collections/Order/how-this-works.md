# Order

Order operations sort and reorder collections.

## Purpose

This folder contains ordering operations.

## Classes

| Class               | Responsibility  |
|---------------------|-----------------|
| `SortValues.php`    | Sort items      |
| `SortValuesBy.php`  | Sort by key     |
| `ReverseValues.php` | Reverse order   |
| `ShuffleValues.php` | Randomize order |
