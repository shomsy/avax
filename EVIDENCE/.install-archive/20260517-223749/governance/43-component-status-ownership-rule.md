# Component Status Ownership Rule

## Decision

The Component Status Ownership rule is added to:
- `how-to-production-readiness.md` — as Section 21
- `how-to-design-components.md` — as Section 22

## Rule Text

Defines 8 allowed component statuses (ACTIVE_GREEN, ACTIVE_YELLOW, ROADMAP, SCAFFOLD, LABS_ONLY, EVIDENCE_ONLY, PURE_FOUNDATION, TEST_ONLY, DEPRECATED) with required fields for each entry.
