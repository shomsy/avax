# DataHandling - Arrhae Component

## Architecture Overview

Modern PHP 8.5 immutable array manipulation library following Feature-Sliced architecture.

```
DataHandling/
├── Arrhae.php                    # Main class (final readonly)
├── Contracts/
│   └── ArrhaeInterface.php       # Public surface contract
└── Traits/
    ├── Access/                   # ArrayAccess, Iterator, Countable
    ├── Aggregation/               # sum, avg, min, max, reduce
    ├── Combine/                  # merge, union, diff, intersect
    ├── Conversion/                # toJson, toArray, toXml
    ├── Lockable/                  # Immutability enforcement
    ├── Order/                     # sort, reverse, shuffle
    ├── Search/                    # contains, where, fuzzy
    └── Transform/                # map, filter, pluck
```

## Quick Start

```php
use Avax\DataHandling\Arrhae;

$arrh = Arrhae::make(['name' => 'Alice', 'age' => 30]);

// Get value
$arrh->get('name');                    // 'Alice'
$arrh->get('address.city');            // Dot notation support

// Immutable transform
$arrh->filter(fn($item) => $item['active'] ?? false);
$arrh->map(fn($item) => $item * 2);
$arrh->pluck('name');

// Search
$arrh->where('age', 30);
$arrh->fuzzyMatch('Alic', 70);

// Aggregate
$arrh->sum('amount');
$arrh->average('score');

// Convert
$arrh->toJson();
$arrh->toXml('item');

// Lock for immutability
$locked = $arrh->lock();
```

## Key Features

- **Immutability**: All operations return new instances
- **Dot Notation**: Access nested values with dot syntax
- **Fuzzy Search**: Levenshtein, phonetic, token matching
- **PHP 8.5 Design**: readonly class, promoted properties
- **Modern Traits**: Cohesive, focused responsibility
