# Engineering Canon Knowledge Layer

Status: CANONICAL_SUPPORT

This directory explains the source principles behind AvaX engineering governance.

It is not a replacement for `.agents/how-to/**`.
Binding rules live in how-to documents, skills, and executable tooling.

Use this layer to answer:

- which external engineering principle influenced a local rule
- which local rule enforces that principle
- whether enforcement is automated, semi-automated, manual review, or educational
- which evidence an agent must write before claiming readiness

Canonical entry points:

- `.agents/knowledge/engineering-canon.md`
- `.agents/knowledge/book-to-rule-traceability.md`
- `.agents/knowledge/source-principles/`
