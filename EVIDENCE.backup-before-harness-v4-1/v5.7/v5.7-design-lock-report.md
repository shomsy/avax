## Key Decisions

### Canonical Owner: `components/Operations/Events/`

Chosen based on audit evidence — it is the most complete general-purpose event system with priority support, stoppable
events, canonical shape, and tests.

### Duplicate Owners Found: 4

| System                                | Scope               | Decision                                         |
|---------------------------------------|---------------------|--------------------------------------------------|
| `Operations/Events`                   | General-purpose     | **CANONICAL OWNER**                              |
| `Operations/MessageBus/EventBus`      | MessageBus handlers | Keep as internal mechanism                       |
| `DataStack/Database/Telemetry/Events` | Database lifecycle  | Keep as internal, future: emit through canonical |
| `HTTP/Session/SessionEventBus`        | Session lifecycle   | Keep as internal                                 |

### Event Model

- Events are plain readonly objects — no `EventInterface` required
- Listeners are invokable classes — no `ListenerInterface` required
- `#[ListensTo]` attribute for declaration-only registration
- `onEvent()->do()` fluent DSL for programmatic registration
- `emit()` for dispatch — returns the event object

### PSR-14 Interop

- Optional dependency (`suggest`, not `require`)
- Adapter wraps AvaX EventEmitter — does not replace it
- User DSL does not expose PSR plumbing
- `StoppableEventInterface` supported via duck-typed check when PSR present

### Compiled Registry

- In-memory for V5.7
- Disk persistence is ROADMAP
- No reflection in hot path
- Boot-time compilation of DSL + attribute declarations
