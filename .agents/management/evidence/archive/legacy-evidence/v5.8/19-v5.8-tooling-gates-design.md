# V5.8-19: V5.8 Tooling Gates Design

**Date:** 2026-05-13
**Stage:** V5.8 Design Lock — Tooling Gates Design

## Future Gate Scripts

### check-database-lifecycle-owner.php

Fails if:
- DB lifecycle code is not inside canonical Database component
- DB lifecycle creates a separate top-level component
- DB lifecycle creates generic Manager/Service/Helper folders

### check-db-lifecycle-no-hot-path-reflection.php

Fails if:
- Runtime scans attributes for lifecycle hooks
- Hot path uses reflection to resolve lifecycle listeners
- Compiled registry is not frozen before runtime

### check-db-lifecycle-compiled-registry.php

Fails if:
- DSL and attribute registrations compile into different registries
- Registry is not frozen after compilation
- Priority ordering is not deterministic

### check-db-aftercommit-safety.php

Fails if:
- afterCommit can run before commit
- afterCommit callback survives rollback
- afterCommit buffer leaks between requests
- Transaction-scoped callbacks use static state

### check-db-outbox-not-eventstore.php

Fails if:
- Outbox code claims to be EventStore
- Outbox docs mention source-of-truth semantics
- Outbox implements aggregate replay

### check-db-lifecycle-dogfooding.php

Fails if:
- Lifecycle listeners are registered but never invoked in tests
- afterCommit is not tested with rollback scenario
- Entity lifecycle is not tested with actual DB persist

### check-db-lifecycle-docs-no-overclaim.php

Fails if:
- Docs claim EventStore production in V5.8
- Docs claim Event Sourcing Kit production in V5.8
- Docs claim production outbox implementation in V5.8 (design only)
- Docs claim production projection engine in V5.8

### check-db-query-redaction.php

Fails if:
- Query telemetry logs raw sensitive bindings
- Redaction is not applied by default
- Raw bindings are accessible without explicit diagnostic mode flag

## Gate Rules

1. **Fail if DB lifecycle creates second generic event dispatcher.**
2. **Fail if runtime scans attributes.**
3. **Fail if afterCommit can run before commit.**
4. **Fail if afterCommit callback survives rollback.**
5. **Fail if docs claim EventStore/EventSourcing production in V5.8.**
6. **Fail if query telemetry logs raw sensitive bindings.**
7. **Fail if lifecycle listeners are decorative and never invoked.**
